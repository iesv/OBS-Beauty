# OBS-Beauty

A lightweight beauty filter for OBS Studio 32.0.4, with dual-scale skin smoothing, light blemish reduction, whitening, rosy tone, sharpening, shadow fill, color adjustment, side-by-side preview and named custom presets.

Supports Windows x64 and macOS Apple Silicon (arm64). Available in English, Simplified Chinese and Traditional Chinese.
